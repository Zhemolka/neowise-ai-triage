# Тестовое Neowise. AI-помощник для входящих заявок

Менеджер вводит текст заявки, получает тему и черновик ответа. Он читает результат и сам решает, что отправить клиенту.

## Запуск

Нужен Node.js 20 или новее. Зависимостей и ключей нет.

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через переменную `PORT`.

## Реализовано

- валидация `POST /api/triage`: пустой, отсутствующий, нестроковый `text` и битый JSON возвращают `400 {"status":"invalid_input"}`;
- ожидание AI ограничено 300 мс через `AbortController`;
- ответ модели проверяется: допустимы темы `delivery`, `pricing`, `other`, а `draft` должен быть непустой строкой;
- при таймауте, ошибке модели или некорректном ответе API возвращает `200 {"status":"manual_review","topic":null,"draft":null}`;
- при `manual_review` интерфейс очищает предыдущий AI-черновик и показывает менеджеру сообщение о ручном разборе;
- добавлены исполнимые тесты для успешного сценария, невалидного ввода, ошибок модели и таймаута.

Для локальной проверки имитатор принимает любой обычный текст. Метки `[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]` включают отдельные сценарии сбоя.

## Тесты

```sh
node --test server.test.mjs
```

## Польза для менеджера

Менеджер не примет пустой или некорректный AI-ответ за готовый результат: при проблеме система явно переводит заявку на ручной разбор. Эффект можно измерять временем первичной обработки и количеством некорректных AI-результатов, дошедших до менеджера.

## Использование AI

Для анализа требований и подготовки черновика изменений использовался ChatGPT. Код, обработка ошибок и граничные сценарии проверены самостоятельно; тесты прогнаны локально.
